# Coinbase × Cursor — sound effects

This folder intentionally contains no new samples. The episode reuses the
licensed Mixkit cues that already exist in:

- `public/audio/episodes/blackberry/sfx/` — UI ticks, keyboard bursts, data
  ticks, editorial reveals, low pulse, system transform, brand signature.
- `public/audio/episodes/airbnb/sfx/` — opening impact, low impact, riser,
  soft whoosh, transition whoosh, brand sting.

Cue list and per-cue volumes live in `src/config/coinbase-audio.ts`.
