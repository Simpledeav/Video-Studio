# LinkedIn

Juicero raised about $120 million for a $699 internet-connected juice press. Then
Bloomberg showed the packs could be squeezed by hand.

The easy lesson is “the product was useless.” The useful lesson is harder: the
machine did have real intended value — consistency, convenience, freshness
checks. But none of it was legible next to the price, the packs and the Wi-Fi
theatre.

Every founder and developer should ask the same question before adding another
dashboard, another AI feature, another authentication layer:

Would the customer still need it if we removed all the fancy technology?

If the answer is no, the complexity is not the product. It is the invoice.
